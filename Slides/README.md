# Qiskit 101 — Lecture & Lab Slides

This directory contains the presentation decks used with the hands-on notebooks in **Qiskit 101: A First Course on Qiskit**.

The intended learning sequence is **lecture → guided discussion → hands-on notebook → competency assessment**. The slides introduce the concepts and activities; the corresponding notebooks provide the executable implementation and learner exercises.

## How to use the materials

### For learners

1. Read or attend the corresponding lecture using the slide deck.
2. Open the companion notebook in Google Colab.
3. Run the examples in sequence and modify selected circuits as instructed.
4. Predict outcomes before executing circuits wherever prompted.
5. Record observations and interpretations, not just numerical outputs.
6. Complete the competency-assessment activities in the notebook.

### For instructors

The slide decks are designed to support a lecture immediately preceding the associated laboratory session. The notebook should remain the primary executable learning artifact, while the slides provide conceptual framing, learning objectives, and an overview of laboratory activities.

## Course design principle

Qiskit 101 follows a **concept-to-code** approach:

> **Concept → Circuit → Execution → Observation → Interpretation → Competency evidence**

This structure is intended to help learners develop both quantum-computing understanding and practical Qiskit skills.

## File naming

The current repository retains the original names of the uploaded slide decks. As the course evolves, filenames may be standardized to the `Lab_XX_...` convention used by the notebooks.
