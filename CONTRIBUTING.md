# Contributing

Contributions that improve correctness, clarity, accessibility, or compatibility are welcome.

1. Fork the repository and create a focused branch.
2. Never include IBM Quantum tokens, credentials, or personal data.
3. Run the affected notebook from top to bottom in a fresh environment.
4. Keep explanations accessible to introductory learners.
5. Submit a pull request describing the learning or technical improvement.

For changes involving hardware output, record the backend, shots, execution date, and relevant software versions. Do not replace pedagogically useful output merely because stochastic counts differ.
