# Course Overview

## Purpose

Qiskit 101 is a practice-led introductory course for learners who know basic Python but may be new to quantum computing. It uses small experiments to connect mathematical concepts, circuits, simulation, hardware constraints, noise, and application-level reasoning.

## Prerequisites

- Basic Python: variables, functions, lists, and imports
- Elementary vectors, complex numbers, and probability
- A Google account for Colab
- An IBM Quantum account for hardware activities in Lab 03

## Learning progression

| Lab | Learner can… | Suggested duration |
|---|---|---:|
| 00 | create a working Qiskit environment and identify installed versions | 45–60 minutes |
| 01 | explain and implement single-qubit state preparation, gates, and measurement | 2–3 hours |
| 02 | compose multi-qubit circuits and interpret correlation and entanglement | 2–3 hours |
| 03 | transpile circuits for a real backend and interpret hardware/noise effects | 2–3 hours plus queue time |
| 04 | implement an end-to-end algorithmic workflow and evaluate noisy outcomes | 3 hours |

## Delivery model

Use a predict–execute–explain cycle:

1. Learners predict the state or measurement distribution.
2. They run or modify the circuit.
3. They compare evidence with the prediction.
4. They explain discrepancies using gates, sampling, transpilation, or noise.

## Assessment approach

Assess competence using three complementary forms of evidence:

- conceptual understanding through short questions;
- practical ability through small coding tasks;
- interpretation through circuit, histogram, and hardware-result explanations.

Notebook assessment sections may be used formatively in class or submitted as a portfolio. For hardware results, evaluate the quality of interpretation rather than expecting identical counts.

## Completion evidence

A learner has completed the course when all five notebooks run successfully, the embedded competency tasks are attempted, and the Lab 04 mini-project contains a circuit, result, evaluation, and brief reflection.
